## Desain & Teknologi
- **Desain:** Neo Brutalism (Pastel Colors, Thick Borders 2.5px, Sharp Shadows, Pink Hot Accent)
- **Font:** Space Grotesk (Google Fonts)
- **Framework CSS:** Bootstrap 5.3.3 + Bootstrap Icons 1.11.3
- **Struktur Halaman:** Pure HTML5 + CSS3 (Tahap Progress 50% Frontend)

## Struktur Folder

campuspass-event-management/
